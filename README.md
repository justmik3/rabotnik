# Работник с Луговой

Мобильная браузерная игра про строителя с Луговой улицы: заказы на Профике, 27 мини-игр, 24 локации, инструмент и транспорт, своя квартира и карьера от разнорабочего до директора.

Графика собрана в Blender. Прогресс сохраняется в браузере.

Играть: откройте страницу GitHub Pages этого репозитория с телефона.

Ссылка на игру: https://justmik3.github.io/rabotnik/
